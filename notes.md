# Concept Sprint Lab

Files created with simple names different from the morning demo:

- `page.html`
- `styles.css`
- `app.js`
- `notes.md`

## What this project combines

- CSS reset, typography, pseudo-elements, transitions, transforms, sticky positioning
- Responsive navigation and media-query behavior
- Grid and flexbox layout patterns
- JavaScript arrays, objects, classes, template strings, and arrow functions
- DOM selection, `createElement`, `innerHTML` for templated sections, and event delegation
- Simulated async behavior with `Promise` and `setTimeout`
- Todo-style task management inspired by the repo mini-projects
