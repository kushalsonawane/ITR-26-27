## Concepts combined

- CSS reset with `*`
- Element, class, id, grouped, and attribute selectors
- Specificity through mixed selector usage
- Box model: margin, padding, border, outline, `box-sizing`
- Display modes: block and inline-block
- Inheritance and typography styling
- Pseudo-classes: `:hover`, `:focus-visible`, `:nth-child`, `:first-of-type`
- Pseudo-elements: `::before`, `::after`, `::first-letter`, `::selection`
- Units: `rem`, `em`, `%`, `vh`, `clamp()`
- Positioning: `relative`, `absolute`, `sticky`
- Float layout with clearfix
- Responsive layout with a media query

## Files3

- `index.html` contains the page structure
- `style.css` contains the combined CSS concepts
