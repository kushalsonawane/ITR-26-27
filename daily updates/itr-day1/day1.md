# Day 1: Internship Orientation & Development Environment Setup

### Objective
Get introduced to the internship path, overview of tools, and verify the baseline workspace.

### Key Learnings
- **Internship Scope**: Understand the progression from web foundations (HTML/CSS) to backend services (Node, Express, PostgreSQL) and React single-page dashboards.
- **Node.js**: Learned that Node is a JavaScript runtime environment built on Chrome's V8 engine that allows executing JS code server-side.
- **Git & Version Control**: Studied standard commands like git init, git commit, git push, and how branch pointers work.

### Code / Terminal Commands Practice
```bash
# Checking installed CLI runtimes
node -v
npm -v
git --version

# Initializing git repo
git init
git config --global user.name "Kushal"
git config --global user.email "kushalwashere@gmail.com"
```

### Practical Exercises Completed
1. Verified Node runtime configurations on local system.
2. Initialized repository, made initial commits, and explored GitHub interface.
