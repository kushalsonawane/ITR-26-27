# Day 6: JS Basics - Variables & Operators

### Objective
Learn basic JavaScript variable keywords and comparison logic operators.

### Key Learnings
- **Variables**: Understood standard differences between `var`, `let`, and `const`.
- **String Indexing**: Read character indexes and computed offsets.
- **Comparison**: Handled equality and value verification.

### Code Practice
```javascript
const name = "Kushal";
console.log(name[0]); // "K"
console.log(name.length); // 6
```
