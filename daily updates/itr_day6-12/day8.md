# Day 8: JS Arrays & Basic Mutators

### Objective
Create collection lists and add/remove array elements from them.

### Key Learnings
- **Collections**: Used standard square bracket arrays.
- **Mutators**: Practiced operations like `push()`, `pop()`, `shift()`, and `unshift()`.

### Code Practice
```javascript
const cart = ["backpack", "shirt"];
cart.push("jacket");
const removed = cart.pop(); // "jacket"
```
