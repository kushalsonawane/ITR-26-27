# Day 7: JS Control Flow & Loops

### Objective
Write conditional logic and loops in JavaScript to manage execution pathways.

### Key Learnings
- **Conditional Logic**: Handled branching using `if-else` statements.
- **Iteration**: Coded standard repeat iterations using `for` and `while` loops.

### Code Practice
```javascript
for (let i = 1; i <= 5; i++) {
  console.log("Iteration number: " + i);
}
```
