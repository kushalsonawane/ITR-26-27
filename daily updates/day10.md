# Day 10: Objects & Property Notation

### Objective
Create object dictionary structures and retrieve parameters using dynamic bracket syntax.

### Key Learnings
- **Objects**: Used key-value maps.
- **Bracket Notation**: Solved dynamic property retrieval.

### Code Practice
```javascript
const user = { name: "Kushal", role: "Admin" };
const attribute = "role";
console.log(user[attribute]); // "Admin"
```
