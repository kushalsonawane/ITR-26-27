# Day 19: BBC Clone Project - Layout & Styling

### Objective
Implement responsive grid layouts mimicking the BBC news homepage.

### Key Learnings
- **Article Grids**: Arranged news cards into asymmetric layouts.
- **Media Queries**: Handled page dimensions for both laptops and mobile viewports.
- **Typography Alignment**: Cleaned margins, borders, and line heights.

### Exercises Completed
1. Replicated BBC news navigation bar containing sections.
2. Arranged columns to drop into single lists on small screens.
