# Day 3: CSS Basics & Styled Components

### Objective
Master core Cascading Style Sheet syntax, properties, selectors, and Box Model components.

### Key Learnings
- **CSS Selectors**: Practiced Element, Class, ID, and grouping selectors to target HTML elements.
- **Box Model**: Explored Content, Padding, Borders, and Margins, and how they define item dimensions.
- **Colors & Fonts**: Used RGB/HEX values, adjusted font-weights, letter-spacing, and line-heights.

### Code Practice
```css
.card {
  width: 300px;
  background-color: #f9f9f9;
  border: 1px solid #e0e0e0;
  padding: 16px;
  margin: 20px auto;
  border-radius: 8px;
  box-sizing: border-box;
}

.card h2 {
  font-family: Arial, sans-serif;
  color: #333;
  margin-top: 0;
}
```

### Exercises Completed
1. Built a user profile card containing details and buttons styled with custom border-radius and shadows.
2. Adjusted margins and paddings on a text block to show behavior difference.
